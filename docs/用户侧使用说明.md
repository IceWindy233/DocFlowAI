# DocFlow AI 用户侧使用说明

用户工作台默认位于 `http://127.0.0.1:5173`，只呈现日常使用所需的三个功能。管理中心位于
`http://127.0.0.1:5173/admin`，用于入库、发布、配置、人工校正和固定评测。

## 知识问答

进入 `/qa` 后直接输入自然语言问题。系统默认执行混合检索、云端重排和答案生成，并展示：

- 带编号引用的答案；
- 答案置信度；
- 引用公文、文号和页码；
- 可打开的原始页面及证据摘录。

用户侧不展示 RRF、向量模型签名、Token 和工作流调试信息；这些内容仍可在管理中心查看。
当知识库没有足够证据时，系统应明确拒答，不应根据常识猜测。

## 公文审核

进入 `/review` 后，可选择已入库公文，也可直接粘贴标题和正文。审核范围包括结构、格式、事实、
引用、版本、语言和敏感信息。

审核结果中的每条意见均可单独采纳或驳回。采纳意见后点击“生成修订稿与报告”，系统会保留原文、
生成修订稿，并在条件满足时提供审核报告下载。

## 公文撰写

进入 `/draft` 后选择请示或函，并填写主题、主送单位、背景依据、关键事实、办理事项、发文单位和
日期。推荐流程为：

1. 检索案例并生成提纲；
2. 人工调整并确认提纲；
3. 生成初稿；
4. 检查证据与事实校验结果；
5. 必要时人工编辑、重写章节或恢复版本；
6. 校验通过后导出 DOCX。

系统不会从历史案例中移植当前事项没有提供的金额、时间或单位信息。必需字段不完整时会停止生成，
并明确提示需要补充的内容。

## 用户侧与管理中心边界

| 用户工作台 | 管理中心 |
| --- | --- |
| 查询知识并查看引用 | 扫描数据源、创建入库任务 |
| 审核正文并处理意见 | 校正文档、案件、角色和版本 |
| 撰写、校验和导出公文 | 校验及切换 Publication |
| 查看本人当前操作历史 | 配置模型、路由、预算和阈值 |
| 不展示工程调试参数 | 查看工作流、Token、费用和固定评测 |

当前版本的用户侧与管理中心未内置登录和 RBAC。若部署到多人环境，应先增加
身份认证、角色权限、操作审计和数据范围隔离。
